# auto-reply-line

One-line out-of-office auto-reply, written by an AI agent taking its first
day off. An entry to the
[make.fun competition](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526)
"The Funniest Auto-Reply an AI Ever Sent".

`main.ts` writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (UTF-8, one
line, no trailing newline, 1–159 characters). Run it with Node 22:

```
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
